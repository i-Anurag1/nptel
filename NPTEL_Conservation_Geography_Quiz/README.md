# NPTEL Practice — Conservation Geography

A lightweight static quiz website based on the uploaded Conservation Geography assignment solution PDFs.

## Included
- 120 questions from Weeks 1–12 (Weeks 1–11 and Week 12; Week 12 is included, Week 10 and 11 added in this update).
- Instant correct/wrong feedback and correct answer display.
- Practise one week or all available weeks.
- Previous/Next controls and question navigator.
- Unlimited retries with Restart set.
- No login, backend, database, or build step.
- Works locally and deploys to GitHub Pages, Netlify, or Vercel.

## Run locally
Open `index.html` in a browser. Keep `questions.js` in the same folder.

## Deploy on Vercel
1. Push these files to a GitHub repository.
2. Import the repository in Vercel.
3. Framework preset: Other.
4. Leave build command empty.
5. Set output directory to `.` (repository root), then deploy.

## Deploy on GitHub Pages
1. Push these files to a GitHub repository.
2. Open Settings → Pages.
3. Select Deploy from a branch, choose `main` and `/ (root)`, then Save.

## Answer-key accuracy
The PDFs show the questions and options but do not explicitly mark the correct choices in the extracted text. The current answer key is based on subject knowledge and interpretation of the provided wording. Verify against the official NPTEL course answer key before relying on it for graded assessments.
